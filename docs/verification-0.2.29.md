# Перевірка 0.2.29 — 26 листопада 2026 року

У блоці додавання групи прибрано лише заголовок «Групи клубу» та речення
«Додавайте основні групи та групи локацій поступово, а потім призначайте
тренерів». Сам блок і кнопка «Додати групу» залишені.

У цьому самому рядку ліворуч показано кількість груп та унікальних активних
гравців вибраної вкладки. Перемикання між основними групами, локаціями та
воротарями змінює ці підсумки. Кількість груп у самих вкладках збережено.

Безпосередньо біля заголовка «Групи» показано загальну кількість активних
гравців клубу. Кожен ID враховується один раз незалежно від додаткового
зарахування до воротарів. Гравці з `is_active=false` не входять до підсумків.
Закриті та майбутні додаткові зарахування не входять до поточного складу.

Нових рядків для підсумків або їх завантаження не додано. Використано
наявне повне посторінкове читання складів; додаткових запитів для лічильників
немає. Поки дані невідомі або читання завершилося помилкою, показується «—»,
а не помилковий нуль. При помилці читання додаткових зарахувань загальний
підсумок активних гравців залишається доступним, якщо самі гравці прочитані.

Перевірено 188 тестами, TypeScript і production build. Нові тести охоплюють
подвійний облік, неактивних гравців, межі дат членства, невідомі/порожні
результати та українські закінчення підписів. Додатково виконано контрольне
читання агрегованих кількостей у робочій базі. Записи бази даних, розклади
та права доступу не змінювалися. Ручний вхід у приватні екрани не виконувався.
