# Перевірка версії 0.2.2

Дата локальної перевірки: 17 вересня 2026 року.

## Зміни

- Додано три повноцінні групи: «Воротарі A», «Воротарі B» і «Воротарі C».
- Воротарські групи зберігаються без штучного віку та не змішуються з U6–U15.
- Адміністратор може призначити одного тренера до однієї або кількох воротарських груп тим самим захищеним механізмом, що й до вікових команд.
- Для воротарських груп працюють гравці, календар, присутність, оплати, форма, інвентар, адміністративні показники, імпорт та експорт.
- У воротарській події можна вказати тему заняття та прикріпити перевірений документ із вправами.
- Вікова методика U6–U15 не підставляється воротарським групам помилково.
- У заголовку застосунку залишається тільки «ЧЕМПІОН».

## Межа перевірки

Локальна перевірка завершена успішно:

- lint — без помилок;
- TypeScript — без помилок;
- 27 автоматичних тестів — пройдено;
