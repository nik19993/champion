# Перевірка 0.2.31 — 26 листопада 2026 року

У розділі адміністратора «Групи» прибрано верхній напис про загальну
кількість груп клубу. Існуючий рядок заголовка показує «Групи N» та
«Гравці M» згідно з погодженим зразком.

N — кількість активних груп у чинному переліку всіх трьох типів.
M — кількість унікальних активних гравців із повного посторінкового
читання. Додаткова участь у воротарських групах не збільшує загальний
підсумок. Невідома кількість під час завантаження залишається «—».
Значення не зафіксовано числами 28 або 334 у вихідному коді.

Змінено тільки властивості заголовка. CSS, рамки, розміщення кнопок,
вкладки, підсумки вибраного розділу, сезон та чинні дії з групами
залишені без змін. Записи бази даних не змінювалися.

Валідація: 188 наявних автоматичних тестів, TypeScript і production build.
Нові тести для зміни підписів не додавалися. Ручний вхід реальним
користувачем для перевірки приватного екрана не виконувався.
