# Перевірка staging 0.2.23

Дата: 29 вересня 2026 року.

## Зміни

- Із довідника «Тестування і оцінювання» видалено зайвий синтетичний показник «Успішні передачі вперед».
- Наявний тестовий результат цього показника без втрати запису перенесено до чинного показника «Лідерські якості».
- Універсальний та спеціалізований шаблони Excel і Word перевірено: показника «Успішні передачі вперед» у них немає, тому змінювати структуру шаблонів не потрібно.
- Експорт списку гравців, профілю гравця, фізичних тестів, ігрової діяльності та заборгованостей формує справжні PDF-файли замість виклику браузерного вікна друку.
- Якщо для запитаного звіту немає записів, завантажується коректний PDF із повідомленням «Дані не внесено».
- Якщо в профілі гравця не заповнено окремі поля, відповідні рядки PDF-профілю містять «Дані не внесено».
- Для нагород «Зірка місяця» збережено погоджене правило: за відсутності відзнак завантажується порожній PDF-звіт, а за наявності переможця без фото формування нагород блокується з точним переліком гравців, яким потрібно додати фото.
- Посилання на сформований файл у браузері зберігається достатньо довго для стабільного завантаження на телефоні та у вбудованому браузері.
