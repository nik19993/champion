# Перевірка версії 0.2.9

Дата: 2026-09-19. Середовище: приватний staging.

## Вихідний код

- Редагований Next.js/TypeScript source відновлено з точної копії релізу 0.2.8; попередній `out` побайтно відповідав staging-збірці.
- Усі зміни 0.2.9 виконані у `app`, `components`, `lib` та Supabase source, а не у скомпільованому `dist`/`out`.
- Походження й контрольні перевірки описано у `source-recovery-2026-09-19.md`.

## Реалізовані сценарії

- Оголошення підтримують конкретні групи, включно з «Воротарі A/B/C»; RLS дозволяє читання тренеру, призначеному до вибраної групи.
- Захищене створення користувача передає JWT адміністратора у перевірку рівня MFA, тому Edge Function більше не втрачає активну сесію; інтерфейс показує точну серверну помилку.
- Наявні терміни редагуються; «манішка» і «маніжка» є словниковими варіантами, у застосунку збережено наявне «манішки».
- Загальна методична бібліотека має довільні розділи та матеріали, не прив’язані до навчальних завдань.
- Імпорт приймає CSV, XLSX і DOCX для п’яти наборів даних та автоматично знаходить відповідний аркуш або таблицю.
- Додано універсальні, заповнені прикладами шаблони Word і Excel.
- Зашифрована адміністративна резервна копія включає нові таблиці методичної бібліотеки.

## Технічна перевірка

- Повний `npm run quality`: пройдено.
- TypeScript typecheck і ESLint: пройдено без помилок та попереджень.
- Контрактні й модульні тести: 43/43 пройдено.
- Оптимізований статичний Next.js build: успішно згенеровано.
- Обидва шаблони відкрито, відрендерено й візуально перевірено; DOCX містить п’ять таблиць даних.
- Міграцію та Edge Functions застосовано лише до staging Supabase.
- Перевірка каталогу staging підтвердила нові таблиці, RLS, групові оголошення та доступ до файлів методичної бібліотеки.

Приватне розгортання фіксується у Git-ревізії релізу.
