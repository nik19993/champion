# Перевірка 0.2.27 — 25 листопада 2026 року

## Групи локацій

Форма створення підтримує A, B, C та Junior. Вікові межі A/B/C збережені:
6–8, 9–12 та 13–17 років. Для Junior вікові межі не задано, оскільки власник
не визначив їх у цьому запиті. Тому автоматичне підставлення програми U6
для цієї категорії прибрано; термінологія та загальні матеріали доступні.
Назва Junior коректно відображається у картці групи.

У робочій базі створено «Локація № 15 Junior», ID
`f6242990-5a6d-4ec2-85ce-4cf360aa9881`, із прив'язкою до чинної локації
№ 15 та її залу. Нових тренерів, гравців чи призначень не створено.
Адміністративне додавання виконане через конектор бази даних і зафіксоване
в аудиті без приписування операції особистому обліковому запису працівника.

## Майданчики

Окреме подання `admin_venue_occupancy_venues` використовується тільки для
адміністративної вкладки «Майданчики». Зал, закріплений за локацією,
приховується, якщо він не використовується основною/воротарською групою
в розкладі або нескасованій події. Враховуються також старі записи половин
майданчиків. Спільний зал залишається видимим.

Записи майданчиків і бронювань не видаляються. Автоматичне призначення залу
локації та серверний контроль накладань залишаються чинними.
Подання має `security_invoker=true`, застосовує права базових таблиць та
вимагає чинного адміністратора з `aal2`; анонімного доступу немає.

## Зірка місяця

Призначений тренер працює з гравцями груп локацій через той самий розділ
«Гравці → Зірка місяця», що й з основними групами. Для адміністратора
додано фільтр результатів: увесь клуб, основні групи, усі групи локацій
або конкретна локація. Окрема група вибирається в сусідньому списку.

Під час транзакційної перевірки виявлено чинну серверну помилку
`invalid input syntax for type interval: "1 month-1 day"` у
`private.validate_monthly_star_award`. Її виправлено на віднімання окремого
інтервалу `1 day` після додавання `1 month`. Збережено перевірку належності
гравця до групи, відповідності теми місяцю та недопуску за чотирма картками.
Адміністратор переглядає результати; переможців визначає призначений тренер.

## Валідація

- 176 автоматичних тестів, перевірка TypeScript та production build.
- Транзакційні SQL-перевірки `0010` та `0011`: усі категорії A/B/C/Junior,
  канонічні назви, повторне створення без дубля, відсутність вигаданого віку,
  склад команди, два переможці й оновлення вибору зі збереженням історії.
- Перевірено відмову сторонньому тренеру, заборону вибору гравця іншої групи,
  доступ адміністратора до результатів та відмову йому в зміні вибору тренера.
- Перевірено приховування окремого залу локації, видимість спільного залу,
  доступність залу для планування тренером та відсутність доступу тренера
  до адміністративного подання.

SQL-перевірки створюють лише тимчасові дані в транзакції з `ROLLBACK`.
Нових Auth-акаунтів для тестування немає. Вхід реальним користувачем
та ручна перевірка приватних екранів у браузері не виконувалися.

Міграція: `20261125202551_location_junior_and_venue_occupancy.sql`.
