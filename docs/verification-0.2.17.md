# Перевірка staging 0.2.17

Дата перевірки: 27 вересня 2026 року.

## Реалізовано

- додано активні групи U16A, U16B, U17A та U17B;
- підтримуваний віковий діапазон у схемі, методиці, оголошеннях, матеріалах і тестуванні розширено до U17;
- старший набір фізичних тестів тепер має діапазон U13–U17;
- до профілю гравця додано необов’язкову «Коротку характеристику тренера» з автором і датою останньої зміни;
- редагувати характеристику може лише активний тренер закріпленої групи, адміністратор має режим перегляду;
- у розділі «Експорт» додано вибір «Усі групи»;
- Excel- і Word-шаблони імпорту оновлено для U16/U17 та старшого набору U13–U17.

## Перевірка бази staging

- 22 активні вікові команди та 3 воротарські групи;
- U16A, U16B, U17A, U17B створені й активні;
- для U16 та U17 доступно по 27 завдань старшої методичної бази;
- структура заняття U9–U17 та чотири активні фізичні тести U13–U17 доступні;
- усі наявні непорожні характеристики мають автора й дату;
- транзакційний pgTAP-сценарій прав доступу та U16/U17: 19/19 перевірок успішні.

## Перевірка source і шаблонів

- `npm run quality`: ESLint, TypeScript, 64/64 контрактні тести та production build успішні;
- усі чотири XLSX-шаблони відкриваються, не містять формульних помилок, випадаючі списки містять U16A/U16B/U17A/U17B;
- універсальний DOCX-шаблон відрендерено на 8 сторінок і перевірено візуально без обрізаного тексту, накладань або пошкоджених таблиць.

Зміни застосовано лише до приватного staging-проєкту. Production не змінювався.
