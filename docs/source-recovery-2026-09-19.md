# Відновлення редагованого frontend source

Дата перевірки: 19 вересня 2026 року.

## Висновок

Оригінальний редагований frontend знайдено. Це повний Next.js-проєкт версії `0.2.8` з каталогами `app`, `components`, `lib`, файлами `package.json`, `package-lock.json`, тестами, міграціями та Supabase Edge Functions.

Відновлений source відповідає Git-коміту:

`7d6170c2cc93e7d7b18b4e33645ae22ff6332719`

Позначка версії у вихідному репозиторії: `v0.2.8`.

## Перевірка відповідності staging

Збережений статичний результат `out` від коміту `7d6170c2cc93e7d7b18b4e33645ae22ff6332719` порівняно з файлами останньої збереженої staging-версії №8, commit:

`e3d0b9715749d9e4705b1bf5dd4fe1456e750405`

Усі файли збірки збігаються за вмістом. Відмінність становили лише три порожні службові каталоги, які не впливають на застосунок.

## Що зроблено

- редагований source перенесено до Git-репозиторію приватного staging;
- каталог скомпільованого `dist` вилучено з поточної source-ревізії, але він залишається доступним у Git-історії;
- для публікації використовується результат нового складання `out`;
- подальші зміни потрібно вносити тільки у TypeScript/React source і перевіряти новим build.

Production-проєкт і production-база під час відновлення не змінювалися.
