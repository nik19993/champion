# Перевірка staging 0.2.21

Дата: 28 вересня 2026 року.

## Зміни

- Усі дати й час у плануванні тренера та адміністратора вводяться й показуються за київським часовим поясом, включно з переходами між зимовим і літнім часом.
- Присутність можна фіксувати до початку, під час або після тренування, гри, турніру, Чемпіонату області, Чемпіонату України та іншої події.
- Присутність і жовті картки поведінки розділено на дві окремі дії. У журналі присутності залишено тільки стани «Присутній»/«Відсутній» без коментаря та без дії «Вихід».
- Жовті картки поведінки доступні тільки для тренувань і тільки для присутніх гравців. Для матчів і змагань фіксується лише присутність.
- Мобільний календар уміщується за шириною екрана без примусової широкої сітки та горизонтального прокручування.
- Фото гравця додається натисканням на компактну область фото: тренер обирає камеру телефона або галерею. Реєстрація файлу виконується захищеною серверною функцією лише для гравця призначеної тренеру групи.
- Імпорт фізичних тестів приймає Excel-дату, `РРРР-ММ-ДД`, `ДД.ММ.РРРР` або спільну дату тестування з інтерфейсу. Повторні повідомлення про одну й ту саму помилку прибрано.
- Оновлено універсальний та спеціалізовані Excel-шаблони для сумісності з Excel і LibreOffice.
